# Issues found and fixed during the order (concise record)

Each entry: what failed, where it was seen, the cause, the fix, and how it is covered now. Failures that were fixed are not erased by later successful runs; they are listed here.

1. **OCR child killed by the address-space limit** (Group A, first OCR run): `_ArrayMemoryError` in the extraction child. Cause: RLIMIT_AS 6 GiB too small for onnxruntime + numpy buffers. Fix: `document_child_address_space_bytes` raised to 32 GiB (still bounded). Covered by test_documents (OCR) and journey 2.
2. **Fahrenheit conversion inexact** (units): float arithmetic produced non-integer base units. Fix: Fraction-based exact conversion with directed rounding (`documents/units.py`). Covered by test_resource_plan (directed conversion) and the locale test.
3. **Import jobs failed MANIFEST_MISMATCH**: contracts did not bind an implementation digest for `document_import`. Fix: DOCUMENT_KINDS bind implementation_digest/source_sha256/policy/attempt. Covered by test_documents.
4. **"database is locked" during publication and model use inside write transactions**: constructing `Services()` or loading a model inside an open `tx()`. Fix: services constructed outside the transaction; `preloaded_generation_host` loads before any write tx (intents, evaluation, reports). Covered by test_intent_model, test_analyses.
5. **Chunks straddling pages** made a search hit the wrong page. Fix: per-page chunking in `publish_extraction`. Covered by test_documents and journey 1 (citation on page 1).
6. **Console table page 409 INTERNAL_DEFECT**: Jinja resolved `r.values` to the dict method. Fix: `r['values']`. Covered by test_console_documents.
7. **Intent compiler**: model consulted with no promoted model (501), schema filter never applied (catalog.list lacks input_schema), evaluation validate_suite treated intent items as knowledge. Fixes: require a model default only when a model choice is needed, key eligibility off `catalog.INSTALLED`, elif chain. Covered by test_intent/test_intent_model.
8. **Resource plan: MILP exclusivity constraint skipped** for pairs declared only on one task (`if j < i: continue`) — the solver returned an overlapping schedule that the exact simulator then rejected. Fix: pair set de-duplication. Covered by the analytic fixture (mutually exclusive alternatives) and 30 random oracle agreements.
9. **Resource plan child failed "Invalid"**: `canonical()` refused floats in plan.json. Fix: exact float encoding (`exactable`) as for calibration. Covered by test_resource_plan_service.
10. **Multi-start rounding candidate accepted**: a relaxation with two starts selected for one task passed the integrality check. Fix: candidates with more than one selected start are rejected by the checker. Covered by the labelled solver-double test.
11. **Freeze-alternative route shadowed** by the generic `/compute/jobs/{id}/{action}` route. Fix: route ordering. Covered by test_resource_plan_service.
12. **Campaign `apply_change` mis-resolved `tasks.<id>.<field>` paths**. Fix: rewritten path walker (lists by index or by record id). Covered by test_resource_plan_service (branch with typed changes).
13. **Analysis view reported a revoked source as current**: the stored snapshot was consulted instead of the live state. Fix: live snapshot for knowledge_document_version references. Covered by test_analyses and journey 21.
14. **Regeneration plan marked export nodes as reruns**. Fix: non-service nodes are always `keep`. Covered by test_analyses.
15. **Package example and export leaked private labels and the source workflow label**: caught by the privacy regression. Fix: private_label stripped recursively from examples; the package name replaces the workflow label in the manifest. Covered by test_privacy_workspace.
16. **Projection heading carried the analysis name** (a user-chosen label): caught by the privacy regression. Fix: neutral heading. Covered by test_privacy_workspace.
17. **Composite quote refused (`quantity_below_work_estimate`)**: node quotes used the default quantity 1. Fix: quantity from the validated work estimate. Covered by test_packages.
18. **Settlement gate reported a stale package-run state**: `gate_for_job` read the row without ticking. Fix: the gate ticks the run first. Covered by test_packages_upto.
19. **Offline verifier crashed on a missing source file** instead of reporting a scope failure. Fix: missing witness/inputs members are reported as failed checks. Covered by test_packages (missing source case).
20. **Document retry after wall-timeout: a queued job-level retry of the superseded attempt ran first** and failed as `stale_attempt` (correct), which the campaign test had not anticipated. Fix: test drives the worker until the new attempt completes; the stale refusal is asserted. Behaviour unchanged (correct).
21. **Journey harness: API frozen on a full stderr pipe** (journey 19 hung after the local-chain build printed deprecation warnings into an unread pipe inherited from the base harness). Fix: task-owned log files for API and worker stderr in the workspace harness. Journey 19 then passed. (Base harness left unchanged for its own journeys, where it did not trigger.)
22. **Journey 13 instance exceeded the 2000 start-variable limit** (2184): the limit worked as designed; the fixture was reduced to 20 tasks (documented in the journey caveat, the limit test is separate).
23. **Continuous batching session never ended after a cancellation**: the manager emits no finished output for a cancelled request, so the session waited for it until the request timeout (612 s). Fix: a cancelled member is finished immediately with its partial output; the session's paged attention is restored after stop. Covered by test_generation_continuous (17 s).
24. **Compatibility check before any worker is live blocks compute operations** (no devices): expected, but journey 18 called it too early. Fix: the journey waits for a live worker; the `no live worker devices` outcome remains a valid blocked result.
25. **Package import apply response lacked `installed`** (journey 18). Fix: field added.
26. **Verify-bundle test expected a projection field NAME to be absent** while the projection legitimately lists withheld field names. Test corrected to assert absence of VALUES; behaviour unchanged.
27. **Consolidated suite at a434618: test_evaluation assumed one generation job per worker claim**; with static generation batching the three queued evaluation items complete in one claim, so the third `run_once()` returned nothing (`'NoneType' object is not subscriptable`). Fix: the test drives the worker until every run job is terminal and asserts all succeeded (assertions strengthened, not weakened). Behaviour unchanged.
28. **Journey 23 harness compared the migration count to a constant (30)** after migration 031 was added. Fix: compare with `len(db.MIGRATIONS)`.
29. **Final journey run: journey 1 search returned no results once** while the consolidated suite, the science suite and the local-chain suite ran concurrently on the host; the same journey passed in the first full run and in the rerun. Fix: the search is retried once after 2 s and both attempts are recorded; the cause (load-induced timing) is reported, not hidden.
30. **Browser check for the package compatibility form ran before a worker was live** (device rows blocked). Fix: the script waits for a live worker and records the page text on failure.
31. **Console package and report forms failed with INTERNAL_DEFECT** (found by the browser journey's compatibility check): the context helpers passed the same keyword twice (`compat=`/`preview=` both in the base dict and in `**extra`). Fix: base dict updated with the extras. Coverage: console form posts added to test_packages (compatibility, instantiate+quote) and test_analyses (projection preview with repeated form keys).
32. **Document import reported `ready` before its knowledge version existed** (journey 1 racing the CLI wait loop: `doc_version` None). The extraction transaction set `ready` and the collection publication ran in a second transaction. Fix: a collection-bound import stays `extracting/publishing` until the knowledge version is published in the same transaction that sets `ready`; a publication failure leaves the import `awaiting_review` with a bounded error. Journey 1 passes deterministically afterwards.
