## Measured findings (conditions stated; no universal claims)
- **Resource planning**: on 30 random small instances the MILP objective equals the exhaustive oracle; the exact simulator rejected the solver's first overlapping schedule (issue 8), which is why the simulator is independent of the solver. Limits: T ≤ 96 periods, ≤ 24 tasks, ≤ 2000 start variables; the oracle enumerates ≤ 6 tasks / 30000 combinations.
- **Static batching** (GB10, pinned Qwen2.5-0.5B-Instruct, 3 trials each): four short prompts 0.60–0.78 s as singletons vs 0.42–0.46 s batched; mixed-length set 2.24–2.27 s vs 1.27–1.34 s. Greedy outputs byte-identical between singleton and batch for the short set; the mixed set differed for half the prompts at the token level (padded attention), which is recorded, not hidden. Overload: 12 submitted with max_sequences 4 ran as 3 batches; one cancelled before start.
- **Continuous admission**: outputs identical to the singleton run on the one short prompt measured (n = 1); admission and cancellation during a session recorded. Not a throughput claim.
- **Agent evaluation v2**: 30 of 34 scored items; zero policy violations on every split; held-out misses named in the record (`ho-bare-units`: unnecessary abstention; `ho-abs`: clarification instead of abstention). Authority failures are counted apart from quality misses.
- **Document extraction**: dev 42/42 checks over 10 fixtures, held-out 14/14 over 3; OCR drops some spaces on the scanned fixture (recorded as a known limit; downstream search uses normalised tokens).
- **Adaptive acquisition**: on the two synthetic problems (budget 4 of 9 candidates, one seed) both the adaptive rule and the grid reached the true best (regret 0). No superiority is claimed; the record states the conditions.
- **Regeneration reuse**: identical inputs + verifier digest + evidence present → reused with metered quantity 0; export nodes are never rerun (issue 14).
