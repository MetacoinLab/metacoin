# MetaCoin

**The credibly neutral money-and-work protocol for the Space Machine Economy.**

> MetaCoin is the first credibly neutral money-and-work protocol for the Space Machine Economy: objective infrastructure work secures the base currency, while a fee-funded treasury pays humans, AI agents, and bounded-autonomous robots to build the research, compute, energy, and robotics primitives needed for humanity's expansion beyond Earth.

## Status
**Research stage. A protocol specification, not a product.** No token, no sale, no airdrop, no investment. Nothing here is financial, legal, or investment advice. See [`legal/`](./legal). The repository *is* the project — there is no marketing website.

## What makes it different
- Fair launch: no founder allocation, no VC, no premine, no hidden reserve.
- Unforgeable base money: the base currency mints only from objectively verifiable work (infrastructure uptime, on-chain liquidity, proof-of-humanity) — never from subjective judgment.
- A fee-funded mission treasury pays the judged work: space research, AI-agent reports, bounded-autonomous robot tasks.
- Hard money only: designed to be priced against Bitcoin and gold-backed assets.
- Machine-native, for space: built for verifiable space work and energy-constrained autonomous systems.

## Lineage (honest)
The `@MetacoinLab` GitHub organization and the `metacoin.ai` domain were both registered in 2023, when the AI-machine-economy thesis was years ahead of the market. That foresight — not 2023 code — is the lineage. The 2026 work is the execution.
